# AI Security Firewall

## Features
- JWT Authentication
- File Upload
- Malware Detection
- YARA Rule Scanning
- AI Prompt Injection Detection
- Phishing Detection
- PDF Report Generation
- Dashboard
- Scan History
- Forgot Password
- Docker Support

## Technology Stack
- Next.js
- FastAPI
- SQLite / PostgreSQL
- ClamAV
- YARA
- JWT
- Docker

## Installation

### Backend
pip install -r requirements.txt
uvicorn app.main:app --reload

### Frontend
npm install
npm run dev

## Deployment
- Frontend: Vercel
- Backend: Render
